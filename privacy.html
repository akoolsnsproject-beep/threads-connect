プライバシーポリシー

アプリ名：mennba-rokuga（メンバー録画）／最終更新日：2026年11月12日

1. このアプリでできること

このアプリは、営業研修を受けるメンバーが、自分の面談（オンラインの営業の打ち合わせ）の録画を、自分の YouTube チャンネルに「限定公開」でアップロードするために使います。あわせて、運営者のアカウントで Google ドライブの録画フォルダを作り、メンバーと共有するために使います。

2. 受け取る情報

  • YouTube：動画をアップロードし、そのアップロードした動画の情報（題名・公開設定）を扱うための許可
  • Google ドライブ：運営者本人のアカウントで、録画フォルダを作成・共有するための許可（メンバーのドライブの中は読みません）

メールアドレス・連絡先・ほかの動画・視聴履歴など、上に書いたもの以外の情報は受け取りません。

3. 情報の使い方と保管

  • 受け取った許可（アクセスの鍵）は、アップロードのためだけに使い、暗号化された保管場所（GitHub の Secrets）に入れます。ファイルやチャットには書きません。
  • 動画は、メンバー本人のチャンネルに限定公開で入れます。題名にお客さんの名前は入れません。
  • 録画の音声や文字起こしは、作業が終わったら残しません。
  • 受け取った情報を、売ったり、広告に使ったり、第三者に渡したりはしません。

4. Google のルールについて

このアプリが Google API から受け取った情報の利用と他のアプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 許可の取り消し・削除

許可は、いつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。取り消すと、このアプリはアップロードできなくなります。保管している許可の削除を希望するときは、研修の運営者の公式LINEで連絡してください。すぐに削除します。
